# BatikFind

BatikFind is a simple page for tourists who want to compare batik designs.

## What the page shows

- Two sample designs side by side
- A name and meaning for each design
- Catalog and contact sections

The names and meanings are sample data. The image boxes are placeholders.

## How to open

Open index.html in a browser, or use Live Server in VS Code.

## Code used

HTML and CSS only. On small screens, the designs appear one below the other.

This is a static demo. Users cannot select different designs yet.
